WEBSITE BUCIN - MUHAMMAD YUDISTIRA CAHYADI

CARA PAKAI:
1. Extract file ZIP ini.
2. Buka folder bucin_muhammad_yudistira.
3. Klik dua kali index.html untuk melihat website di browser.

GANTI FOTO:
- Buka folder img.
- Ganti file SVG placeholder dengan foto milikmu dalam format JPG/PNG.
- Cara termudah: simpan foto dengan nama yang sama (misalnya foto-utama.jpg), lalu ubah ekstensi src di index.html dari .svg menjadi .jpg.
- File yang bisa diganti: foto-utama, foto-berdua, foto-kamu, galeri-1, galeri-2, galeri-3.

GANTI TANGGAL:
- Buka script.js.
- Tanggal jadian sudah diatur ke 2022-04-02. Jika ingin mengubahnya, edit tanggalJadian = "2022-04-02" menjadi tanggal kalian (format YYYY-MM-DD).

MUSIK:
- Pemutar video musik To The Bone dari kanal resmi Pamungkas sudah ditanamkan melalui YouTube.
- Klik tombol play di video. Browser biasanya tidak mengizinkan musik otomatis berjalan tanpa interaksi.

UPLOAD:
- Bisa diunggah ke Vercel, Netlify, atau GitHub Pages sebagai website statis.
